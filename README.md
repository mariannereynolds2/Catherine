# Catherine J. Mottier

Site officiel de l'autrice de thrillers Catherine J. Mottier : une seule page, en français, avec ses romans, sa biographie et ses contacts.

Toutes les images sont intégrées dans `index.html`, aucun autre fichier n'est nécessaire.

Publication sur Cloudflare Pages : aucune commande de build, dossier de sortie `/`.

Site créé par [Halcyon Literary House](https://halcyonliterary.com).
